# House Renovation Plan

## Project Goal
Create a cleaner, more cohesive front elevation and side elevation update while keeping the home’s original proportions and architectural character. The goal is to modernize the exterior through new materials and horizontal lines, while maintaining white windows and a simplified, refined entry.

## Key Design Requirements

### 1) Front brick
- The front brick will be changed using a brick sample provided by the homeowner.
- Brick samples can be supplied as links or images.
- This brick is for the front elevation only, unless otherwise specified.

### 2) Front and side aluminum / siding
- The front aluminum and side aluminum will be replaced using a siding/aluminum sample provided by the homeowner.
- The material for both front and side non-brick areas should match the same selected sample.
- The selected material must be horizontal.
- The front aluminum that replaces the current vertical aluminum must also be horizontal.
- The side materials must be horizontal as well.

### 3) Front columns
- Existing front columns are white and round.
- Reduce the column size by 10%.
- Keep them white.
- Use a simple square white cap on top.
- Keep the columns minimal and clean.

### 4) Front door trim
- Remove the white wood trim around the front door.
- Keep the front entry clean and flush.
- Do not add heavy trim or decorative framing around the door.

### 5) Windows
- Keep all windows white.
- The aluminum between the windows and around the bay window should be updated to match the same overall clean, horizontal look.
- The window surround material should feel consistent with the rest of the home.

### 6) Door design
- The new front door must be based on the provided door reference image.
- The door should include two side glass panels, one on each side of the door.
- Each side panel should be a single full-glass panel, not three panes.
- The glass should be frosted like the door glass, matching the style in the door reference.
- The side panels should visually match the door design.

### 7) Overall material approach
- Front brick: one selected brick sample
- Front + side non-brick materials: one selected horizontal siding/aluminum sample
- Keep all exterior finishes consistent and cohesive across the front and side elevations.

## Required Inputs for Future Renderings
To generate new design studies, provide only the following:

1. Brick material sample
   - Image or link for the new front brick

2. Side/front material sample
   - Image or link for the new horizontal aluminum / siding material

3. Door image
   - The reference door image, such as door.jpg

## Base Image Workflow
For consistency across all renderings, the original house reference photos should be stored in a fixed project folder and reused every time instead of being re-uploaded in the prompt.

### Recommended folder structure
- `house_renderings/base_images/`
- `house_renderings/base_images/front_house/`
- `house_renderings/base_images/front_house_garage/`
- `house_renderings/base_images/reference_door/`

### Required base images
- One base image of the front of the house without renovation changes
- One base image of the front house with garage view, if needed for alternate render studies
- One reference image for the door design

### Standard use
When generating new renderings:
- always use the same saved house base image(s)
- only replace the material samples and door reference if necessary
- keep the house geometry and camera fixed across all renderings

This creates a consistent visual baseline so comparing materials is easier and more reliable.

## Reusable Rendering Workflow
This brief is meant to stay simple and easy to reuse:

- Use the stored base image(s) from the project folder
- Replace the brick sample with a new image or link
- Replace the horizontal siding/aluminum sample with a new image or link
- Keep the same design intent and constraints
- Re-render without rewriting the project brief

## Best Practice for Material Comparisons
To make material decisions easier, each new rendering should be generated from the same base image and differ only in:
- brick sample
- siding/aluminum sample
- any minor adjustment to front entry finish if needed

This makes it easier to compare true material choices side-by-side.

## Final Notes for Reuse
- The house should feel cleaner, brighter, and more modern without losing its original shape.
- Keep the front entry simple and streamlined.
- Keep the windows white and the columns soft white.
- Maintain one consistent horizontal material language across the front and sides.
- Use the provided door image as the design anchor for the new front entry.
- Adjust brightness and luminosity so the render feels natural and realistic, not artificially overlit or overly dark.
- Keep the overall lighting balanced and consistent with real exterior daylight conditions so material comparisons remain fair.
